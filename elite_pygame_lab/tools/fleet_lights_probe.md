# Огни собственного флота

- [Контактная таблица всего каталога](../previews/fleet_lights.png)
- [Автопролёт «До / После»](../previews/fleet_lights_flyby.mp4)

Бирюзовыми номерами отмечены 17 моделей со световыми профилями. У Rock Hermit сигнал работает в искусственной шахте. Обломок, валун и астероид показаны для сравнения. Для каждой карточки камера стоит неподвижно и обращена к освещённым деталям. Thargoid снят со стороны −X, Thargon со стороны +X. Из 24 фаз на карточку выбрана фаза с наиболее заметным освещением.

Видео показывает Viper, пиратскую Cobra, Fer-de-Lance, Thargoid, Thargon и Dodo. У каждого пять секунд штатного автопролёта в темпе 1×. Viper снят на втором круге, когда к камере обращена патрульная пара огней. Слева принятый рендер с огнями Cobra №09 и торгового Python №10. Справа рендер со всеми профилями. В паре совпадают камера, время, позы и свет звезды. Каждая сторона снята в 960 × 540 с MSAA 4× и вставлена без масштабирования.

В демо **B** переключает огни и свечение. Запуск с выключенными эффектами доступен через `--no-effects` в режимах `space` и `flyby`.

## Воспроизвести

Для сравнения нужен снимок предыдущей версии со светом у Cobra №09 и торгового Python №10 и исходными ресурсами. Снимите обе стороны на одном GPU с одинаковым драйвером. Активируйте Python-окружение с `requirements-space.txt`. Для ролика нужен `ffmpeg` с `libx264`.

Из текущего `elite_pygame_lab` укажите каталог снимка, в котором лежат `elite_lab`, `tools`, `asset_packs` и `reference_data`.

```bash
previous=/путь/к/снимку/elite_pygame_lab
cp tools/ship_lights_probe.py tools/fleet_lights_probe.py "$previous/tools/"
(cd "$previous" && python -B tools/fleet_lights_probe.py --reference-only --audit-dir /tmp/elite-fleet-before)
python -B tools/fleet_lights_probe.py --reference-dir /tmp/elite-fleet-before --audit-dir /tmp/elite-fleet-after
```

`--still-only` записывает таблицу без MP4. `--output-dir` меняет каталог результатов. Оба отчёта `capture.json` содержат настройки GPU, исходники и сетки с SHA-256, часы фаз и хеши кадров, матриц и теней. В каталогах аудита остаются исходные RGB8 PNG карточек. Для сравнения каждый кадр видео декодируется из потока RGB8 принятой версии и сверяется с его SHA-256 перед записью MP4.

## Проверка

Штатный маршрут проверяется каждые 1,5 секунды за полный круг. Дополнительно сравниваются все кадры ролика, все собственные модели в изолированных сценах, импортированные сетки в обоих режимах текстур и каркас ZX. При остановленной геометрии меняются только часы, по которым рассчитывается свечение. За пределами проекций новых целей учитывается поле 24 пикселя для ореола и допускается один шаг RGB8.

На Apple M2 Max с OpenGL 4.1 все 900 кадров ролика и 84 среза кольца с выключенными эффектами совпали с принятой версией побайтово. С включёнными эффектами совпали и области за пределами новых целей и их ореолов. Проверены 411 изолированных кадров, по 24 фазы каждого из 17 профилей и по кадру каждого пассивного объекта. Все 48 фаз принятых Cobra и Python совпали. Сетки GPU и карты теней совпали. Ошибок OpenGL нет.

В 51 контрольном кадре импорта и ZX эффекты не назначались. Для импортной процедурной обшивки сравнение двух версий выявило округление до двух шагов RGB8 в 68 пикселях на шести кадрах. При сравнении положений переключателя расхождение затронуло три пикселя на двух кадрах. Авторские текстуры и ZX совпали побайтово.

# Огни Cobra и Python в автопролёте

Историческое сравнение показывает первую пробу огней, пульсации сопел и мягкого свечения на Cobra Mk III №09 и торговом Python №10. Инструмент оставляет в сравнительных сценах только эти два профиля. Текущий атлас показывает [профили всего собственного флота](fleet_lights_probe.md).

- [Сравнение в движении](../previews/cobra_python_lights_flyby.mp4)
- [Ключевые кадры рядом](../previews/cobra_python_lights_flyby.png)

Двенадцать секунд штатного автопролёта со скоростью 1×. Показ начинается за три секунды до центра участка Cobra Mk III №09. На шестой секунде камера переходит к торговому Python №10. Ключевые кадры сняты на 7,30 и 14,93 секунды по часам сцены, когда видны кормовые сопла. Каждая сторона рендерится в 960 × 540 с MSAA 4× и вставляется в сравнение пиксель в пиксель. У пары общий ракурс, позы кораблей и свет звезды.

## Запуск в демо

Из `elite_pygame_lab` в окружении с `requirements-space.txt` выполните

```bash
python -m elite_lab --mode flyby --model 9 --model-source elite --texture-source procedural --source-interval 0
```

Клавиша **B** переключает огни, пульсацию сопел и ореолы всего флота. Для старта с выключенными эффектами добавьте `--no-effects`.

## Повторить захват

```bash
python -B tools/ship_lights_probe.py --audit-dir /tmp/elite-lights-current
```

Для MP4 нужен `ffmpeg` с `libx264`. Ключевые кадры можно снять отдельно с `--still-only`. PNG и MP4 записываются в `previews`, путь можно заменить через `--output-dir`. В каталоге проверки остаются исходные PNG и `capture.json` с параметрами GPU, SHA-256 кода и мешей, хешами кадров, поз, света и теней.

Чтобы сверить выключенные эффекты с исходной ревизией, подготовьте её снимок из текущего `elite_pygame_lab`. Обе стороны нужно снять на одном GPU с одинаковым драйвером. Окружение Python должно быть активировано перед запуском команд.

Строгий `--baseline` рассчитан на версию первой пробы с двумя профилями. В текущей версии компиляция GLSL может иначе округлить отдельные пиксели импортной процедурной обшивки. Численная сверка таких кадров входит в [проверку всего флота](fleet_lights_probe.md).

```bash
snapshot=$(mktemp -d)
git -C .. archive e7190d84d54adeb33076bea71910f1b90c622637 elite_pygame_lab | tar -x -C "$snapshot"
cp reference_data/blueprints.bin reference_data/dodo_elite_legend.bin "$snapshot/elite_pygame_lab/reference_data/"
cp tools/ship_lights_probe.py "$snapshot/elite_pygame_lab/tools/"
(cd "$snapshot/elite_pygame_lab" && python -B tools/ship_lights_probe.py --baseline-only --audit-dir "$snapshot/audit")
python -B tools/ship_lights_probe.py --baseline "$snapshot/audit/capture.json" --audit-dir /tmp/elite-lights-current
```

Захват проверяет RGB8 до кодирования MP4. Для каждого кадра сравниваются матрицы поз и света, входные данные карты теней и область кольца за пределами проекций двух освещённых моделей с полем 24 пикселя для ореола. В этой области допускается разница до одного шага RGB8 из-за округления HDR. Для ключевых кадров дополнительно считывается сама карта глубины теней. Отдельная серия держит геометрию неподвижной и меняет только часы эффектов. Контрольные кадры включают ZX, остальные классические корабли и импортированные Cobra/Python с авторскими и процедурными текстурами. Новые собственные профили отмечаются отдельно и участвуют в сверке выключенного режима.

## Проверка первой пробы на Mac

На Apple M2 Max с OpenGL 4.1 все 360 кадров с выключенными эффектами и 26 контрольных кадров побайтово совпали с ревизией `e7190d8`. Сетки в GPU-буферах совпали с исходными вершинами. Обе серии с остановленной геометрией дали по 72 разных кадра с включёнными эффектами при неизменном исходном RGB8. Ошибок OpenGL нет.

В нативном оконном режиме Retina на Apple M2 Max четыре выборки MSAA зеркальны по вертикали относительно внеэкранного буфера. Из-за разных позиций выборок при переключении эффектов могут различаться отдельные пиксели на сглаженных контурах. При выключенных эффектах кадр совпадает с `e7190d8`. Для внеэкранных кадров и фиксированного разрешения проверка за пределами ореолов дала до одного шага RGB8.

Медиана прогретого `draw()` с ожиданием GPU в сцене 960 × 540 составила 1,50 → 1,96 мс на участке Cobra и 1,50 → 1,92 мс на участке Python. В замер входит обновление карты теней при движении камеры.

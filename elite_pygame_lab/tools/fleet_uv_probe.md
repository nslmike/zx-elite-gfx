# Проверка UV классических кораблей

- [Крупные планы пяти рёбер до и после](../previews/fleet_uv_closeup.png). Каждый кадр 768 × 480, исходные камеры аудита и вертикальный угол обзора 42°. Голубые штрихи отмечают место стыка по обе стороны от ребра.
- [Полные корпуса с двух сторон до и после](../previews/fleet_uv_overview.png). Viper, Asp Mk II и Fer-de-Lance показаны сверху и снизу, Thargoid и Thargon со сторон +X и −X. Каждый кадр 410 × 268.

В каждой паре совпадают камера, поза, геометрия, нормали, материалы и освещение. Штатный рендерер заново снял обе версии. Карта теней рассчитана для каждого корпуса, затем тот же буфер вершин получает старые и новые UV. Видимые перегибы фасет сохраняются. На проверенных стыках панели, решётки и их рельеф теперь переходят между фасетами непрерывно.

| Модель | Ребро | Угол фасет | Расхождение до, медиана | Расхождение после, максимум |
|---|---:|---:|---:|---:|
| №08 Viper | 1–8 | 36,7° | 242 текселя | 0 |
| №13 Asp Mk II | 11–12 | 13,5° | 77 текселей | 0 |
| №14 Fer-de-Lance | 8–9 | 38,1° | 136 текселей | 0 |
| №15 Thargoid | 4–12 | 23,5° | 148 текселей | 0 |
| №18 Thargon | 4–9 | 42,5° | 96 текселей | 0 |

Расхождение измерено в 129 точках на каждом ребре с учётом масштаба и повтора карты 2048 × 2048. На обзорных кадрах обе версии стороны −X у Thargoid и Thargon совпали побайтно. Визуальная проверка охватывает 15 указанных ракурсов.

## Повторить захват

Из `elite_pygame_lab` в окружении с `requirements-space.txt` экспортируйте исходные меши пяти кораблей из ревизии `47ed93e`. Команда читает старый сборщик из Git и сохраняет массивы во временном каталоге.

```bash
baseline_dir=$(mktemp -d /tmp/elite-fleet-uv-baseline.XXXXXXXX)
python - "$baseline_dir" <<'PY'
from pathlib import Path
from subprocess import check_output
import sys
from types import ModuleType

import numpy as np

baseline = ModuleType("elite_lab._fleet_uv_baseline")
source = "47ed93e:elite_pygame_lab/elite_lab/space_mesh.py"
exec(compile(check_output(["git", "show", source]), source, "exec"), baseline.__dict__)
for model in (8, 13, 14, 15, 18):
    np.save(Path(sys.argv[1]) / f"before-{model:02}.npy", baseline.build_mesh(model))
PY

raw_dir=$(mktemp -d /tmp/elite-fleet-uv-frames.XXXXXXXX)
python tools/fleet_uv_probe.py --baseline-dir "$baseline_dir" --raw-dir "$raw_dir" --atlas
```

Инструмент сверяет SHA-256 исходных мешей с аудитом и проверяет побайтовое совпадение позиций, нормалей и материалов обеих версий. `--atlas` добавляет в каталог исходных кадров диагностические изображения общей карты без освещения. Для штатных кадров используется обычный шейдер. Готовые листы пишутся в `previews`, другой каталог можно указать через `--output-dir`.

Захват проверен на Apple M2 Max в OpenGL 4.1 Metal с 4× MSAA. Все 30 штатных и 30 диагностических кадров получены с `GL_NO_ERROR`. В каждой паре совпали хеши переданных GPU параметров света и позы. На крупном плане каждого корпуса совпали хеши карты глубины тени, обзорные кадры использовали эту же карту. В `capture.json` сохраняются точные координаты камер и рёбер, SHA-256 исходников, мешей и RGB, а также сведения OpenGL.

## Missile, Sidewinder и Krait

- [Крупные планы трёх рёбер до и после](../previews/small_ships_uv_closeup.png). Камеры и разрешение 768 × 480 взяты из исходного аудита.
- [Полные корпуса с двух сторон](../previews/small_ships_uv_overview.png). У Missile передний и задний ракурсы показывают нос и кили. У Sidewinder и Krait сняты верх и низ.

| Модель | Ребро | Угол фасет | Расхождение до, медиана | Расхождение после, максимум |
|---|---:|---:|---:|---:|
| №01 Missile | 2–3 | 14,0° | 26,56 текселя | 0 |
| №16 Sidewinder | 0–4 | 15,5° | 43,12 текселя | 0 |
| №17 Krait | 0–1 | 15,5° | 20,59 текселя | 0 |

На штатном крупном плане Missile эффект слабый, диагностическая карта отчётливо показывает совмещение рисунка на обтекателе. У Sidewinder сравнение показывает обшивку вокруг фонаря, у Krait — панели по обе стороны верхнего гребня. На всех трёх корпусах сохранилась детализация панелей и решёток. Проверка охватывает девять ракурсов.

Для повторения экспортируйте из `47ed93e` модели `(1, 16, 17)` по команде выше и добавьте `--group small` к запуску. Команда сохраняет два листа `small_ships_uv_*.png`.

В OpenGL 4.1 Metal на Apple M2 Max с 4× MSAA сняты 18 штатных и 18 диагностических кадров. Все имеют `GL_NO_ERROR`. SHA-256 кадров сверены с `capture.json`. В каждой паре совпали хеши позы, света и карты тени. Шейдер и настройки материала, включая силу рельефа, совпали с исходным снимком.

# Отражения и шероховатость Cobra и Python

Проба включена у собственных классических Cobra Mk III №09 и торгового Python №10. Металл получает отражение окружения, размытое в соответствии с шероховатостью поверхности. У краски, открытого сплава, потёртостей и графитового стекла своя шероховатость. Мелкая вариация закреплена на корпусе и ослабляется, когда её перестаёт разрешать экранный пиксель.

В карте освещения сохранена холодная подсветка обшивки и добавлена мягкая направленность. Шесть граней видимого неба, направление и интенсивность звезды, рассеянная подсветка и экспозиция прежние. Карты цвета, металлические маски, потёртости и свечение сохранены. Высота, сила и способ расчёта слабого bump не менялись.

Для отражений предварительно рассчитываются шесть уровней GGX-фильтрации небольшой HDR-карты окружения и таблица отклика материала. Одна и та же шероховатость применяется к блику звезды и отражённому окружению. Карта отражений и таблица занимают примерно 1,35 МиБ. Диск звезды исключён из этой карты, поскольку звезда уже учитывается прямым источником света. [Описание IBL в Filament](https://google.github.io/filament/main/filament.html)

## Посмотреть в демо

Из `elite_pygame_lab` в окружении с зависимостями `requirements-space.txt` выполните

```bash
python -m elite_lab --mode flyby --model-source elite --texture-source procedural --model 9 --source-interval 0
```

Для старта у Python замените `--model 9` на `--model 10`. Клавиша **F** передаёт камеру для свободного полёта. Отдельный осмотр открывается через `--mode space --model 9` или `--mode space --model 10`.

## Воспроизвести сравнение

```bash
python tools/hull_material_probe.py --raw-dir /tmp/elite-material-comparison
```

Нужны OpenGL и `ffmpeg` в PATH. Флаг `--still-only` сохраняет только изображения и не требует видеокодировщика. Результаты записываются в `previews`, другой каталог задаётся через `--output-dir`.

- [Крупный план Cobra и Python](../previews/cobra_python_materials_closeup.png)
- [Одинаковый момент автопролёта](../previews/cobra_python_materials_flyby.png)
- [Сравнение в движении](../previews/cobra_python_materials_flyby.mp4)

В каждой паре одинаковы камера, геометрия, UV, время вращения, свет звезды и экспозиция. Слева прежние отражения и шероховатость, справа пробный материал. Python с обеих сторон использует исправленную развёртку, поэтому изменение расположения панелей не вмешивается в сравнение материалов. Области кадров сохраняются без увеличения пикселей. В каталоге `--raw-dir` остаются исходные PNG и JSON с ракурсами, хешами, сведениями о GPU и временем отрисовки.

Ролик состоит из двух фрагментов по 4,5 секунды при 30 кадрах/с. Каждый воспроизводит первые 2,23 секунды штатного автопролёта в половинном темпе. Замедление относится только к записи, скорость демо прежняя.

Программное переключение доступно через `renderer.look.refined_materials_enabled` перед следующим `draw()`. В обычном просмотрщике проба включена. Для остальных собственных моделей и всех импортированных корпусов этот переключатель не меняет материал.

## UV Python

У торгового и пиратского Python №10/11 верх и низ корпуса теперь имеют по одной общей проекции X/Z в прежнем масштабе. Это устраняет разрывы на 14 внутренних стыках этих поверхностей. Корма, граница верха и низа, накладные детали и апертуры двигателей сохраняют отдельные области развёртки.

Геометрия, нормали и номера материалов сохранены. Развёртка Cobra Mk III прежняя. Слабый рельеф Python следует тем же исправленным UV, что и цвет панелей. Последующие исправления других корпусов описаны отдельно. [Проверка UV классических кораблей](fleet_uv_probe.md)

[Отдельное сравнение стыка Python со старой и новой развёрткой](../previews/cobra_python_materials_python_uv.png) снято с прежним материалом на обеих сторонах.

Чтобы повторить именно UV-сравнение, сохраните `AssetCatalog().classic[10].vertices()` из ревизии `47ed93e` как NumPy-файл, затем передайте его инструменту через `--uv-baseline /путь/к/python10.npy`. Инструмент проверяет совпадение позиций, нормалей и номеров материалов перед сравнением.

## Проверка на Mac

Кадры сняты на Apple M2 Max в OpenGL 4.1 с MSAA 4×. Между состояниями до/после побайтово совпали рассчитанные на GPU нормали, цвет, металличность, маски износа и свечение обеих пробных моделей. Меняются шероховатость и отражённый свет. В 68 контрольных вариантах остальных собственных и импортированных моделей весь кадр совпал побайтово. Ошибок OpenGL нет.

В прогретой внеэкранной сцене автопролёта 1360 × 820 медианное время отрисовки с ожиданием GPU составило 1,20 мс до и 1,52 мс после. Это замер конкретного кадра без интерфейса и оконной синхронизации. Подготовка отражений при первом запуске добавляет около 0,9 секунды. Пройдены 162 модульных теста.
